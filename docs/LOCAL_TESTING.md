# Проверка в локальной игре

Всё в этом списке уже работает на сервере без графики. Там проверены загрузка, рецепты, скрипты и тесты столкновений
(81/81) в шести наборах модов. Но на сервере без графики нельзя открыть окно, увидеть картинку или построить что-то
руками. Поэтому ниже — только то, что надо посмотреть глазами в обычном клиенте Factorio 2.1.

Автоматическую часть (загрузка в разных наборах модов с настоящей графикой, самотест) может сделать локальная
сессия Claude Code на вашем ПК — см. [LOCAL_SESSION.md](LOCAL_SESSION.md). Ниже — то, что смотрит человек.

## Подготовка

1. Моды: `FreightForwarding_2.0.0.zip`, `IntermodalContainers-continued_2.1.5.zip`, **Fluid Must Flow 1.5.1**
   (обязательная зависимость), cargo-ships, остальные зависимости FF. Для второго прохода включите Space Age.
2. Новая игра, пресет карты **Freight Forwarding Default**, в редакторе карты включите «Песочницу» или используйте
   команды ниже (сохранение будет без достижений — это нормально для теста).
3. Удобные команды консоли (`~`), выполнять по одной:

```
/c game.player.force.research_all_technologies()
/c game.player.cheat_mode = true
/c for _, n in pairs{"ff-pipeline-landing","ff-duct-landing","ff-pipeline-segment","ff-insurance-office","ff-cable-landing","ff-subsea-cable","ff-tank-container","ff-port-crane","ff-cable-terminal","pipe","storage-tank","offshore-pump","chemical-plant","substation","solar-panel"} do if prototypes.item[n] then game.player.insert{name=n, count=50} end end
```

Если что-то не так — пришлите **скриншот** и файл `factorio-current.log`
(Windows: `%APPDATA%\Factorio\factorio-current.log`, Linux: `~/.factorio/factorio-current.log`,
macOS: `~/Library/Application Support/factorio/factorio-current.log`), а также номер пункта ниже.

## 1. Контейнеры-цистерны (расширенный режим)

- [ ] В меню крафта у упаковки и распаковки Intermodal Containers есть свои вкладки цистерн. Иконки оранжевые,
      на них видна жидкость.
- [ ] Названия читаются: «Контейнер-цистерна: 2000 Нефтяной газ», рецепты «Заполнить…/Слить…».
- [ ] Химзавод: рецепт заполнения выбирается, в окне видно 2000 единиц жидкости на входе. Цистерна выходит.
- [ ] Слив: возвращается 2000 жидкости и пустая цистерна (иногда — повреждённая или ничего, это потеря 1% / 2%).
- [ ] Цистерна грузится в корабль, поезд и (со Space Age) в ракету: в ракету влезают 2 полные цистерны.
- [ ] Технология «Контейнеры-цистерны» показывает в описании «по 2000 единиц».

## 2. Подводный трубопровод

- [ ] Береговой узел трубопровода (голубой оттенок) ставится на берегу и **не ставится на воду** и на космическую платформу.
- [ ] Поставьте два узла на одной линии **лицом друг к другу** через воду (до 255 клеток).
      Пока ничего не проложено, жидкость между ними не идёт и подземная стрелка-подсказка до второго узла не тянется.
- [ ] Откройте узел — появилось окно «Подводный трубопровод»: узел напротив (ссылка gps), расстояние,
      сколько сегментов нужно, время, кнопка «Проложить трубопровод». Без сегментов строка стоимости красная.
- [ ] Нажмите «Проложить»: сегменты списываются, по воде растёт синяя пунктирная линия, в окне — «осталось …».
- [ ] По окончании сообщение «Подводный трубопровод до … готов». Узлы называются «… (проложен)», жидкость идёт
      (насос → узел → вода → узел → бак).
- [ ] Окно на проложенном узле пишет «Соединён с …».
- [ ] Разберите один узел: сообщение «разорван», второй узел снова непроложенный, в инвентарь вернулся обычный узел.
- [ ] Если узел напротив не найден, окно пишет подсказку.
- [ ] **Узел магистрали (Fluid Must Flow)**: то же самое с большим 2×2 узлом на основе воздуховода FMF. Требует
      4 сегмента на клетку. Соединяется только с воздуховодами FMF, не с обычными трубами.
      Проверьте, что графика FMF выглядит нормально (голубой оттенок, без «битых» картинок).
- [ ] Обычная подземная труба, поставленная рядом, **не** соединяется с подводным узлом под землёй.

## 3. Страховка грузов

- [ ] Страховая контора (зелёный стальной сундук) строится, внутри 96 ячеек.
- [ ] Загрузите вагон или корабль и уничтожьте его (`/c game.player.selected.die()`, наведя курсор на вагон).
      В ближайшей конторе появилась половина груза, в чате сообщение «Страховка: потерян …, выплачено … (50%)».
- [ ] Настройки карты → «Страховая выплата за груз, %»: при 0 ничего не приходит, при 100 приходит всё.
- [ ] Обычная разборка вагона (не уничтожение) **ничего** не выплачивает.

## 4. Архипелаг

- [ ] В «Новая игра» → пресеты карты есть «Freight Forwarding — Архипелаг». Превью карты — много мелких островов.
- [ ] «Новая игра» → «Сценарии»: есть «Архипелаг (Freight Forwarding)» с описанием.
- [ ] При старте сценария показывается вступление про Архипелаг (не стандартное «Welcome to Factorio Freeplay»).
- [ ] Слева вверху — цель «Архипелаг: Изучите грузовые корабли». После изучения (можно командой
      `/c game.player.force.technologies["cargo_ships"].researched = true`) через 2 с сообщение «Цель выполнена»,
      в инвентаре награда (2 порта, 10 буёв), цель сменилась на «Постройте два порта» со счётчиком 0/2.
- [ ] Стартовый остров примерно 200×200 клеток, рядом есть суша, есть вода для насоса.
- [ ] Со Space Age сценарий тоже запускается и ведёт к обычной победе Space Age / FF.

## 4а. Датчик груза, биржа, маршруты, Великий караван

- [ ] **Датчик груза** рядом с остановкой: при стоящем поезде с контейнерами в его сигналах видны распакованные
      товары, число контейнеров, % загрузки и флаг «стоит». Когда поезд ушёл, сигналы пропадают.
- [ ] **Биржа каравана**: открыть сундук — справа панель с выбором «Получать», кредитом, комиссией, таблицей цен
      со стрелками тренда. Положить контейнеры руды, выбрать контейнер плит — через 10 с они обменяны.
      Копирование настроек (Shift+ПКМ / Shift+ЛКМ) переносит выбор на другую биржу.
- [ ] **Панель маршрутов** (третья кнопка FF на панели быстрого доступа): список поездов и кораблей, фильтр
      «Все / Корабли / Поезда», застрявшие красным сверху, ссылки на карту работают, обновляется раз в 2 с.
- [ ] **Великий караван** (Space Age): `/c remote.call("ff-freight-contract","great_now",1)` — в панели
      контрактов появляется голубое предложение «Великий караван: …», в чате сообщение. Чертежи:
      `/c remote.call("ff-freight-contract","set_reputation",1,6)` — сообщения о трёх чертежах, рецепты
      «(чертёж каравана)» доступны, комиссия биржи 5%.
- [ ] **Советы и хитрости**: в разделе Freight Forwarding новые советы (датчик груза, маршруты, цистерны,
      трубопровод, кабель, морская инфраструктура, страховка, биржа, Великий караван).

## 4б. Сухой док, планировщик земснарядов, планеты

- [ ] **Сухой док** у порта: у сундука справа панель «Менять корабли на». Положить ремкомплекты — повреждённый
      корабль у дока чинится. Положить быстрый грузовой корабль и выбрать его — стоящий корабль заменяется,
      груз и расписание сохранены, старый корабль в доке.
- [ ] **Планировщик земснарядов** (кнопка на панели быстрого доступа после «Земснаряды»): выделить море с
      разведанными подводными горами — появляются призраки платформ, сообщение «запланировано / пропущено /
      не разведано». Alt-выделение — лучший изученный земснаряд.
- [ ] **Лавовая баржа Mk2** (Вулканус): значок Mk2 и планеты на иконке, трюм вдвое больше.
- [ ] **Криоцистерны** (Аквилон): цистерна аммиака через 50 мин становится «наполовину выкипевшей»,
      рецепт переохлаждения в криогенном заводе возвращает полную.
- [ ] **«Живые» рефконтейнеры**: включить в настройках карты, рефконтейнер в поезде с биофлюсом портится
      как обычно, без корма — быстрее.

## 5. Ранее сделанное, что тоже видно только в клиенте

- [ ] **Кнопки на панели быстрого доступа**: «Статистика контейнеров» и «Контракты» открывают и закрывают свои панели.
- [ ] **Контракты** (Space Age): в панели видны предложения с таймерами, кнопка «Принять», срок, штраф,
      обновление предложений; после доставки партии на край системы — прогресс.
- [ ] **Подводный кабель**: окно берегового узла кабеля, прокладка, линия на воде, после — медный провод.
      На Глебе нужен болотный кабель, на Наувисе — подводный.
- [ ] **Пропуска доставки** (FF + SA): исследовательский пост появляется недалеко от исследованной зоны
      (метка на карте). Его нужно починить, затем доставить материалы, после чего вылетает капсула
      (анимация, звук) и запускается отсчёт 5 минут до самоуничтожения.
- [ ] **Значки уровней и планет**: на иконках кораблей, земснарядов и контейнеров Mk2/Mk3 — в углу сверху,
      планета — внизу.
- [ ] **Земснаряды Mk2 (6×6) / Mk3 (8×8)**: платформа 24×24 / 30×30 не кладётся на фарватеры, рельсы и поезда.
- [ ] **Датчик порчи** у остановки показывает сигналы M и A для стоящего поезда.
- [ ] **Морская инфраструктура**: портовый кран (дальний захват), ветряк в море и приливная станция
      (выработка меняется), кабельный терминал.
- [ ] **Опасности**: на Фульгоре бури, на Вулканусе урон кораблям в лаве, на Глебе замедление на болоте,
      на Аквилоне без ледокола тяжело.
- [ ] **Переводы**: переключите язык на украинский, французский, немецкий, японский — нет строк вида `Unknown key`.

## 6. С другими модами (по желанию)

Если в игре стоят: Krastorio 2 или K2 Spaced Out (оба режима), Alien Biomes, LTN, Cybersyn, AAI Containers,
Factory Planner, Helmod, Rate Calculator, Recipe Book, Milestones, Better Victory Screen, планеты (Cerys,
Maraxsis, Muluna, Moshine), AAI Industry — просто загрузите новую игру и пройдитесь по паре пунктов выше.
Все эти наборы загружаются на сервере без ошибок. В клиенте нужно смотреть только картинки и окна.
