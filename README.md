# Svasf — Freight Forwarding для Factorio 2.1

* `FreightForwarding/` — мод Freight Forwarding 2.0.0, перенесённый с Factorio 1.1 (версия 1.9.0) на 2.1, с необязательной поддержкой Space Age.
* `IntermodalContainers/` — неофициальный порт Intermodal Containers 2.1.3 → 2.1.4 для Factorio 2.1 (GPL-3, авторы Xorimuth, RedRafe, Deadlock989).
* `docs/PORT_2.1.md` — что изменено, как проверено и что нужно проверить в игре.
* `docs/SPACE_AGE_IDEAS.md` — идеи по адаптации под Space Age.
* `tools/mock-data-stage/` — проверка data-стадии и noise-выражений без запуска Factorio.

Чтобы установить мод, упакуйте папку как `FreightForwarding_2.0.0.zip` (внутри — папка `FreightForwarding_2.0.0/`) и положите в папку `mods`.
